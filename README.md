# Highkeep: free antivirus, scam site blocker and link checker for Windows

**Website and download: https://highkeeplabs.com**

Highkeep is free security software for Windows 10 and 11:

- **Antivirus** that stops password stealers and ransomware by what they do, so new versions get caught too
- **Scam and malware site blocker** plus an ad and tracker blocker
- **Link checker** that marks links safe or dangerous before you click, on every site (Discord, Gmail, Reddit and more)
- **Browser extension** for Chrome and Edge (Highkeep Shield)

Free guides: [how to spot a fake download](https://highkeeplabs.com/guides/how-to-spot-a-fake-download/),
[Discord scams](https://highkeeplabs.com/guides/discord-scams/), and
[where to safely download 50+ popular apps](https://highkeeplabs.com/guides/#apps).

## About this repository

This repository hosts the website and the released files. Highkeep checks every update for its release signature
before installing it. File checksums: [SHA256SUMS.txt](SHA256SUMS.txt). Report security problems privately:
https://highkeeplabs.com/report/
