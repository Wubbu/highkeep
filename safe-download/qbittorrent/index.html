Download qBittorrent safely

qBittorrent is the free, ad-free torrent client. Fake download sites for apps this popular are a common way malware spreads, so here's exactly where to get the real one.

The quickest safe way: winget

Windows 10 and 11 come with winget, Microsoft's package manager. It downloads qBittorrent from the source listed in Microsoft's catalog, so there's no search result to get wrong. Open Terminal (right-click the Start button) and paste:

winget install --id qBittorrent.qBittorrent -e

Or go to qbittorrent.org by typing the address yourself, rather than clicking a search ad.

Watch out for

  • qBittorrent is free and has no ads. The program is safe; most of what people download with it is not. Pirated games and programs are a top source of malware.
  • Search ads above the real results. Scammers buy ads for popular app names, so the first link can be a fake. Scroll past the ads, or type the address yourself.
  • Look-alike addresses: an extra word, a dash, a swapped letter or a different ending (.org instead of .com).
  • Downloads that arrive as a password-protected .zip, or as a .scr, .bat, .js or .vbs file. Real installers are .exe or .msi files.
  • Pages that tell you to turn off your antivirus or Windows Defender before installing.

Check the file before you run it

  1. The download should come from sourceforge.net/projects/qbittorrent (your browser's download list shows where a file came from).
  2. Right-click the installer → Properties → Digital Signatures. It should be signed by the company or project behind qBittorrent.
  3. If Windows SmartScreen or your antivirus warns you, stop and check where the file came from before clicking past it.
