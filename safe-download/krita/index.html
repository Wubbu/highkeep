Download Krita safely

Krita is the free digital painting app. Fake download sites for apps this popular are a common way malware spreads, so here's exactly where to get the real one.

Updated November 2026

Made byKrita Foundation

The quickest safe way: winget

Windows 10 and 11 come with winget, Microsoft's package manager. It downloads Krita from the source listed in Microsoft's catalog, so there's no search result to get wrong. Open Terminal (right-click the Start button) and paste:

winget install --id KDE.Krita -e

Or go to krita.org by typing the address yourself, rather than clicking a search ad.

Watch out for

  • "Pro", "premium" or "cracked" versions of free apps sold or shared elsewhere are a common way malware spreads.
  • Search ads above the real results. Scammers buy ads for popular app names, so the first link can be a fake. Scroll past the ads, or type the address yourself.
  • Look-alike addresses: an extra word, a dash, a swapped letter or a different ending (.org instead of .com).
  • Downloads that arrive as a password-protected .zip, or as a .scr, .bat, .js or .vbs file. Real installers are .exe or .msi files.
  • Pages that tell you to turn off your antivirus or Windows Defender before installing.

Check the file before you run it

  1. The download should come from download.kde.org (your browser's download list shows where a file came from).
  2. Right-click the installer → Properties → Digital Signatures. It should be signed by the company or project behind Krita.
  3. If Windows SmartScreen or your antivirus warns you, stop and check where the file came from before clicking past it.
